# Maintained compatibility packages

These packages are included from the versions previously locked by this distribution. Their upstream constraints or APIs predate Neos 8.4. Local changes keep the existing integrations working with Neos/Flow 8.4; Composer installs them through a path repository.

- **Sfi.Styleguide** (`sfi/styleguide`): https://github.com/sfi-ru/Sfi.Styleguide.git, commit `4ecddfa191d5cf05e49df3469d49b720519609a9`.
- **Sfi.Grid** (`sfi/grid`): https://github.com/psmb/Sfi.Grid.git, commit `2ba9c4294eb2749830c6bd14e5a5ca2d653fe10e`.
- **Psmb.Newsletter** (`psmb/newsletter`): https://github.com/psmb/Psmb.Newsletter.git, commit `81f73b1961d6fd7f53d9e3e34823b62ff302b4ab`.
- **Psmb.Term** (`psmb/term`): https://github.com/psmb/Psmb.Term.git, commit `71f871fb3af0f625d365cfb069fd6f32083bb27e`.
- **Flowpack.Mustache** (`flowpack/mustache`): https://github.com/Flowpack/mustache.git, commit `82a0f3be286a12dae29cb3823decccb7c280f400`.
- **Yeebase.Graylog** (`yeebase/graylog`): https://github.com/dimaip/Yeebase.Graylog, commit `fc18d9165321cf8ee889d5b18ec99a1ca86d5fc0`.
- **Psmb.Footnote** (`psmb/footnote`): https://github.com/psmb/Psmb.Footnote.git, commit `ef23cea5772bf6370b1f44c13bdc22783ca07c14`. Rebuilt CKEditor extension for Neos UI 8.4.
